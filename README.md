# Personal Assignment 2 week 7  - Linked List & Stack dan Queue

## deskripsi
Pengimplementasian data structure dan algorithma menggunakan bahasa pemograman java pada data struktur:
- Linked List (Operasi tambah, hapus, dam cari data) program pengelolaan daftar buku perpustakaan
- Stack & Queue program sistem kasir toko

## Fitur Program

### 1. Perpustakaan (Linked List)
- tambah buku
- hapus buku
- cari buku
- Tampilkan semua buku

### 2. Sistem Kasir (Stack & Queue)
- tambah antrian pelanggan
- layani pelanggan 
- tampilkan antrian
- lihat riwayat transaksi

## Struktur Projeck
- Perpustakaan: linked list
- SistemKasirToko → Stack & Queue

## Cara Menjalankan
- Jalankan MainPerpustakaan.java
- Jalankan MainKasir.java
